# learn data pipelines with phoebe

How one order becomes a dashboard - in plain English. A six-session, zero-code on-ramp to data
pipelines for anyone who reads dashboards but never built one.

**Live site:** https://phoebefu6.github.io/learn-data-pipelines-with-phoebe/

## The course

One order record - #8412, a $42 coffee gift bundle bought at 11:41pm - travels from the checkout
app to the Monday 9am revenue dashboard. Six sessions walk the road:

1. **Follow the order** - the six-stage journey, and why the Friday spreadsheet always dies
2. **Where data is born** - sources, the overnight pickup, batch vs streaming
3. **The cleanup room** - raw to ready, and the ETL vs ELT story
4. **The last mile** - dashboards, metric definitions, and the schedule that runs the floor
5. **When pipelines break** - stale vs wrong, the four failure causes, and the interactive
   pipeline floor (break every stage yourself)
6. **People, tools, next steps** - roles, the tool-name decoder table, and how to ask for data

Every tool name (Snowflake, dbt, Airflow, Fivetran, Looker) gets decoded into a plain-English
job description. Sources and coverage are documented honestly in
`materials/official-course-map.md`.
